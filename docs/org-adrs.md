# Organization ADRs binding lodge

Decisions from [frostyard/core](https://github.com/frostyard/core/tree/main/docs/adr) that this repository follows:

- [ADR-0071](https://github.com/frostyard/core/blob/main/docs/adr/0071-hold-every-code-repository-to-one-baseline.md): the repository baseline (core's `docs/specs/repository-baseline.md`, rows B1 to B17); `internal/workflowcheck` checks the files of rows B1, B2, B6 and B13. [ADR-0073](https://github.com/frostyard/core/blob/main/docs/adr/0073-let-ci-run-the-make-ci-targets-as-separate-jobs.md): CI runs the targets of `make ci` as separate jobs.
- [ADR-0002](https://github.com/frostyard/core/blob/main/docs/adr/0002-agent-portable-instruction-surface.md), [ADR-0018](https://github.com/frostyard/core/blob/main/docs/adr/0018-org-wide-agent-instruction-and-knowledge-surfaces.md), [ADR-0029](https://github.com/frostyard/core/blob/main/docs/adr/0029-acmm-conformance-via-canonical-aliases.md): `AGENTS.md` is canonical. `CLAUDE.md`, `GEMINI.md`, `.cursorrules` and `.github/copilot-instructions.md` are relative symlinks to it, and `.claude/skills` is a symlink to `.agents/skills/`. `.memory/corrections.jsonl` is the corrections inbox.
- [ADR-0011](https://github.com/frostyard/core/blob/main/docs/adr/0011-frostyard-prefixed-package-names.md): the package is `frostyard-lodge`.
- [ADR-0012](https://github.com/frostyard/core/blob/main/docs/adr/0012-svu-versioning-and-rolling-dev-prerelease.md), [ADR-0053](https://github.com/frostyard/core/blob/main/docs/adr/0053-name-the-svu-config-svu-yml.md): svu versions lodge's `vX.Y.Z` tags with `.svu.yml`; `make bump` tags `svu next`.
- [ADR-0019](https://github.com/frostyard/core/blob/main/docs/adr/0019-governance-as-code-and-risk-tiers.md), [ADR-0068](https://github.com/frostyard/core/blob/main/docs/adr/0068-label-pull-requests-that-touch-high-risk-paths.md): risk tiers in the PR template; `.github/risk-paths.json` and its caller `.github/workflows/risk-paths.yml` label a PR that touches a high-risk path `risk:high`.
- [ADR-0021](https://github.com/frostyard/core/blob/main/docs/adr/0021-sha-pinned-actions-and-least-privilege-ci.md): CI actions are pinned to full commit SHAs, with least-privilege permissions (`internal/workflowcheck`).
- [ADR-0023](https://github.com/frostyard/core/blob/main/docs/adr/0023-verified-pinned-downloads.md): downloads are version-pinned and checksum-verified.
- [ADR-0025](https://github.com/frostyard/core/blob/main/docs/adr/0025-consolidate-repository-docs-into-docs.md): one `docs/` tree in the four-category shape.
- [ADR-0038](https://github.com/frostyard/core/blob/main/docs/adr/0038-scope-the-test-name-filter-to-chairlift.md): `make ci` is the canonical gate, and tests run without a name filter. It supersedes ADR-0022, so lodge has no `TestI` reservation.
- [ADR-0043](https://github.com/frostyard/core/blob/main/docs/adr/0043-pin-repository-tools-in-mise-and-name-the-verify-gate.md), [ADR-0044](https://github.com/frostyard/core/blob/main/docs/adr/0044-expose-the-make-gate-triad-in-every-repository.md): tools are pinned in `mise.toml` with `mise.lock`, and the gates are `make verify`, `check` and `ci`.
- [ADR-0057](https://github.com/frostyard/core/blob/main/docs/adr/0057-run-first-party-apps-behind-lodge.md): frostyard's first-party apps run behind lodge. This is the platform decision these docs build on.
- [ADR-0058](https://github.com/frostyard/core/blob/main/docs/adr/0058-ship-suite-desktop-apps-as-flatpaks-and-services-as-sysexts.md): lodge ships as a `.deb` that installs only under `/usr`, so a sysext can carry it.
- [ADR-0070](https://github.com/frostyard/core/blob/main/docs/adr/0070-build-tool-docs-sites-with-materialx-on-github-pages.md): a documentation site in `site/` on GitHub Pages (not built yet).
- [ADR-0072](https://github.com/frostyard/core/blob/main/docs/adr/0072-write-every-readme-to-one-standard.md): the root `README.md` follows core's README spec for the kind `service`.
